# 💍 Digitālā Vienreizlietojamā Kamera

Kāzu foto/video kamera viesiem.

Datums:
**08.10.2026**

---

## Funkcionalitāte

- Viesis noskenē QR kodu
- Ievada savu vārdu
- Nospiež "Sākt fočēt"
- Izvēlas:
  - 📷 Uzņemt Foto
  - 🎥 Ierakstīt Video
- Telefons atver kameru
- Kadrs automātiski tiek nosūtīts uz Dropbox
- Viesis redz tikai savu darbību
