Pirms iesniegšanas praktikants dienasgrāmatā ievada faktiskos datumus un sev
atbilstošo stundu uzskaiti. Dokumenti un ekrānattēli pierāda paveiktā darba
saturu, bet paši par sevi automātiski nepierāda nostrādāto laiku.

Sākotnēji iesniegtā uzskaite bija **120/160 h**. Atlikušajiem darbiem lietotājs
norādīja 40 h plānu un pats ievada ierakstus dienasgrāmatā pēc to izpildes.
