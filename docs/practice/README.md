## Nākamie soļi

1. Apstiprināt jaunās R2 readable folders SQL migrācijas izpildi.
2. Pievienot Supabase/Netlify/R2 paneļu ekrānattēlus bez secrets.
3. Izpildīt autorizētu testa pasākuma plūsmu un pierakstīt rezultātus.
4. Pievienot faktiskā iPhone/Android testa dienu un ierīces informāciju.
5. Iesniegt gala prakses veidni, prakses vietas datus un pašvērtējumu.

Lietotāja iesniegtā faktiskā uzskaite joprojām ir **120/160 h**.
Pēc reālo darbu ievadīšanas to var atjaunināt. Šie materiāli nav fiktīva 160 h uzskaite.
